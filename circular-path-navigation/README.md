# Circular Path Navigation Design

Standalone design artifacts for the Circular Path desktop navigation redesign.
This folder is intentionally separate from `rapid-assessment-studio`.

## Files

- [desktop-navigation-options.html](desktop-navigation-options.html): review
  prototype with four desktop navigation directions shown over the current
  Circular Path homepage context.
- [assets/circular-path-homepage-context.jpg](assets/circular-path-homepage-context.jpg):
  first-viewport homepage capture used as the prototype backdrop.

## Options In The Prototype

- Option A: Zimmermann-style editorial menu.
- Option B: AKIRA-style full-width mega menu.
- Option C: compact department menu.
- Option D: collaboration-first header.

Option A is the preferred comparison direction. It mirrors the Zimmermann
desktop pattern: slim announcement bar, larger centered logo, utility icons,
pipe-separated uppercase department links, and a wide white dropdown with text
columns plus editorial image tiles.

The Circular Path wordmark is rendered about 30% larger than the earlier
prototype treatment.

Open the HTML file directly in a desktop browser to review the options.
